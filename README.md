# Europa.vim

![artwork](https://img.p3ac0ck.net/figs/europa-vim.png)

A Vim/Neovim plugin that orbits Jupyter — running on Deno, no Python on the host, `.ipynb` as a first-class citizen.

For details, see [`:help europa`](./doc/europa.txt).
A runnable JupyterLab-flavored sample config lives in [`sample.vimrc`](./sample.vimrc) (see also [`:help europa-jupyterlab-mappings`](./doc/europa-mappings.txt)).
