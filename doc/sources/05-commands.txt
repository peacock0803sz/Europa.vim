==============================================================================
COMMANDS						*europa-commands*

							*:EuropaOpen*
:EuropaOpen [path]
	Open {path} as a Europa viewer buffer. When {path} is omitted the
	current file (`%`) is used. The buffer is set to `modifiable=false`
	and `conceallevel=0`.

	This command is also triggered automatically by `BufReadCmd` when
	you open any `*.ipynb` file with `:edit`.

							*:EuropaPreviewOutput*
:EuropaPreviewOutput {cellIdx} {outputIdx}
	Write the image output at cell index {cellIdx} and output index
	{outputIdx} to a temporary file and open it with the OS default
	image viewer:
	  macOS   `open`
	  Linux   `xdg-open`
	  Windows `cmd /c start`

	Both arguments are zero-based integers. The placeholder line in the
	buffer shows the exact command to run, for example: >
	  [image: png 640x480 - :EuropaPreviewOutput 3 0]
<
	Only image MIME types (`image/png`, `image/jpeg`) are supported.
	Calling this command on a non-image output prints a message and does
	nothing.

CELL EDITING COMMANDS~
						*europa-commands-editing*

							*:EuropaInsertCell*
:EuropaInsertCell {type} [{position}]
	Insert a new empty cell of {type} (`code`, `markdown`, or `raw`)
	relative to the cell at cursor. {position} is `before` or `after`
	(default `after`).

	:EuropaInsertCell! {type}
		Equivalent to `:EuropaInsertCell {type} before`.

	Example: >
	  :EuropaInsertCell code
	  :EuropaInsertCell markdown after
	  :EuropaInsertCell! raw
<
	See also: |:EuropaDeleteCell|, |:EuropaCellType|,
	          |<Plug>(europa-insert-code)|

							*:EuropaDeleteCell*
:EuropaDeleteCell
	Delete the cell at the cursor position. If this is the last cell,
	the viewer shows an empty-notebook guidance message.

	See also: |:EuropaInsertCell|, |<Plug>(europa-delete-cell)|

						*:EuropaMoveCellUp*
:EuropaMoveCellUp
	Swap the cell at cursor with the cell immediately above it in the
	notebook. No-op with a guidance message if already at the top.

	See also: |:EuropaMoveCellDown|, |<Plug>(europa-cell-up)|

						*:EuropaMoveCellDown*
:EuropaMoveCellDown
	Swap the cell at cursor with the cell immediately below it in the
	notebook. No-op with a guidance message if already at the bottom.

	See also: |:EuropaMoveCellUp|, |<Plug>(europa-cell-down)|

							*:EuropaSplitCell*
:EuropaSplitCell
	Split the cell at cursor into two cells at the current line.

	When called from a viewer buffer, the split point is resolved
	relative to the cell's source lines. When called from a scratch
	edit buffer (see |:EuropaEditCell|), the cursor line maps directly
	to the source.

	The upper cell retains the original cell ID, outputs, and
	execution_count. The lower cell gets a new UUID and empty outputs.

	See also: |:EuropaJoinCell|, |<Plug>(europa-split-cell)|

							*:EuropaJoinCell*
:EuropaJoinCell
	Join the cell at cursor with the cell immediately above it. The
	surviving cell retains the upper cell's ID, type, outputs, and
	execution_count. Sources are concatenated with a newline separator.

	No-op if cursor is on the first cell.

	See also: |:EuropaSplitCell|, |<Plug>(europa-join-cell)|

							*:EuropaEditCell*
:EuropaEditCell
	Open the source of the cell at cursor in a scratch buffer named
	`__europa_cell_<id>__`. The scratch buffer has `buftype=acwrite`
	so that `:write` commits the edited source back to the notebook
	and re-renders the viewer.

	A second call on the same cell reuses the existing scratch buffer
	(`:buffer <scratchBufnr>`).

	See also: |:EuropaSplitCell|, |<Plug>(europa-edit-cell)|

							*:EuropaCellType*
:EuropaCellType {type}
	Change the type of the cell at cursor to {type} (`code`, `markdown`,
	or `raw`).

	  code → markdown/raw: `outputs` and `execution_count` fields are
	                        removed from the cell.
	  markdown/raw → code: `outputs` and `execution_count` are
	                        initialized to `[]` and `null`.

	If a scratch edit buffer is open for the cell, its `filetype` is
	updated to match the new cell type.

	See also: |:EuropaEditCell|

KERNEL COMMANDS~
					*europa-kernel-commands*

							*:EuropaStartKernel*
:EuropaStartKernel [{name}]
	Start or connect to a Jupyter kernel for the current buffer.

	{name} is the kernel name to start (e.g. `python3`, `ir`).  When
	{name} is omitted the value of |g:europa_default_kernel| is used
	(default: `python3`).

	The command is asynchronous: it returns immediately and the kernel
	connection is established in the background.  Progress and errors
	are reported via |:messages| (e.g. `EuropaKernelError: ...`).

	Example — explicit kernel name: >
		:EuropaStartKernel python3
<	Example — use default kernel: >
		:EuropaStartKernel
<
	See also: |g:europa_default_kernel|, |g:europa_jupyter_url|,
	|g:europa_use_subprocess|

							*:EuropaShutdownKernel*
:EuropaShutdownKernel
	Shut down the kernel attached to the current buffer and release its
	server-side session.

	The command is asynchronous: it returns immediately and kernel teardown
	proceeds in the background.  Progress and errors are reported via
	|:messages|.

	Cleanup is automatic on three other paths:
	  - `:bwipeout` of the notebook buffer fires the `BufWipeout` autocmd,
	    which shuts down the attached kernel as part of buffer cleanup.
	  - Quitting Vim (`:qa!`, normal exit) fires `VimLeavePre`, which shuts
	    down every active kernel via the `atexit` dispatcher.
	  - If Vim is killed with SIGKILL, the watchdog subprocess detects the
	    parent's death and kills the Jupyter server process within 15 s.

	When `g:europa_use_subprocess = v:false` (external server mode), the
	session DELETE is sent but the Jupyter server process is not killed.

	See also: |:EuropaStartKernel|, |g:europa_use_subprocess|

							*:EuropaKernelStatus*
:EuropaKernelStatus
	Display the current kernel connection status for the buffer in
	|:messages|.

	When a kernel is attached, the output includes:
	  - Kernel name and kernel ID
	  - Kernel execution state (`starting`, `idle`, `busy`,
	    `reconnecting`, or `disconnected`) and WebSocket state
	  - Reconnection progress (`retry: 2/5`) when reconnecting
	  - Language name and version (from the kernel_info_reply)
	  - Server reference count (number of buffers sharing the process)

	When no kernel is attached: >
	    Europa: No kernel attached to this buffer.
	    Use :EuropaStartKernel to start one.
<
	All four connection states (before start, connected, reconnecting,
	disconnected) are handled without crashing (SC-011).

	See also: |:EuropaStartKernel|, |:EuropaShutdownKernel|

PHASE 4+ COMMANDS (NOT YET AVAILABLE)~
						*europa-commands-future*
The following commands are planned for Phase 4 and later.

	`:EuropaRun`		Execute the current cell against the kernel.
	`:EuropaRunAll`		Execute all cells in order.
	`:EuropaRestartKernel`	Restart the running kernel.
	`:EuropaInterruptKernel` Send an interrupt to the kernel.
	`:EuropaAttach`		Attach to an existing connection file (Phase 4).
