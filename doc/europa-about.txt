PHASE ROADMAP~
						*europa-about-roadmap*
Phase 2 (current): Read-only `.ipynb` viewer with rich output rendering
		   and experimental Sixel inline images.
Phase 3 (planned): Cell execution, kernel management, full inline image
		   rendering via Kitty Unicode Placeholder.
Phase 4 (planned): Direct ZMQ attach to an existing kernel connection file,
		   advanced MIME types (Vega-Lite, PDF).
Phase 5 (planned): ipywidgets comm support, cell editing.
