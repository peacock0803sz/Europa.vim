INTRODUCTION						*europa-introduction*

Europa.vim turns your Vim/Neovim into a moon of Jupyter: a quiet orbit around
`.ipynb` notebooks, viewed directly inside the editor. It runs on Deno via
denops.vim, gives identical behaviour on both hosts, and keeps the host
Python-free — no `pip install` of plugin dependencies required.

Phase 2 (current) provides read-only viewing and round-trip saving. Opening
a notebook renders each cell with Unicode border decoration and highlights
rich outputs: plain text, streams, tracebacks, JSON, Markdown, and HTML.
Images are shown as text placeholders by default; an experimental Sixel
path is available for terminals that support it.

Kernel connection, cell execution, and cell editing land in Phase 3.

QUICK START~
							*europa-quickstart*
1. Open any `.ipynb` file: >
	:edit path/to/notebook.ipynb
<
2. The buffer is read-only (`modifiable=false`). Each cell is framed by
   `╭─ In [N] ─╮` / `╰─ Out [N] ─╯` decorations.

3. To open an image output in the system image viewer: >
	:EuropaPreviewOutput {cellIdx} {outputIdx}
<
   The cell and output indices appear inside the placeholder line shown in
   the buffer.

4. To save back to disk in canonical `.ipynb` format: >
	:write
<
