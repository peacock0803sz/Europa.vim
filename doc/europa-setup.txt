==============================================================================
SETUP							*europa-setup*

INSTALLATION~
							*europa-setup-install*
Europa.vim requires denops.vim. Install both with your plugin manager.

lazy.nvim: >
	{
	  "vim-denops/denops.vim",
	  {
	    "peacock0803sz/Europa.vim",
	    ft = "ipynb",
	  },
	}
<
vim-plug: >
	Plug 'vim-denops/denops.vim'
	Plug 'peacock0803sz/Europa.vim'
<
dein.vim: >
	call dein#add('vim-denops/denops.vim')
	call dein#add('peacock0803sz/Europa.vim')
<

DENO~
							*europa-setup-deno*
Install Deno from https://deno.land/ or via your system package manager.
Verify the installation: >
	deno --version
<
Europa.vim does not install Deno automatically.

IMAGEMAGICK (OPTIONAL)~
						*europa-setup-imagemagick*
Needed only for the experimental Sixel backend. Install via your OS package
manager, for example: >
	brew install imagemagick        # macOS
	apt install imagemagick         # Debian / Ubuntu
<
Check that `magick` (or `convert`) is on PATH: >
	magick --version
<

==============================================================================
LSP (PYRIGHT / RUFF / TY, OPTIONAL)~
						*europa-setup-lsp*
For *python* notebooks, |:EuropaEditCell| can open an LSP-ready mirror buffer
so your own language servers attach (see |g:europa_lsp_enable|, default
"auto").  Europa never starts a server itself; markdown / raw cells and
non-python notebooks are not mirrored.

Install a type checker plus ruff -- use pyright OR ty for type checking, and
ruff for lint + format.  Running all three at once is fine: >
	pip install pyright ruff ty       " or: npm install -g pyright
<
Configure your LSP client to attach on the `python` filetype; it will pick up
the mirror file under `<workspace-root>/.europa/lsp/`.  Examples:

nvim-lspconfig: >
	require("lspconfig").pyright.setup({})
	require("lspconfig").ruff.setup({})
<
vim-lsp: >
	au User lsp_setup call lsp#register_server({
	  \ 'name': 'pyright', 'cmd': {->['pyright-langserver','--stdio']},
	  \ 'allowlist': ['python']})
<
coc.nvim: install `coc-pyright`, and register ruff as a separate server.

Notes:
- Add `.europa/` to your project `.gitignore` (the mirror lives there).
- Format on save is delegated to your client (e.g. ruff formatting on
  `BufWritePre`); Europa absorbs the result on `:w`.
- All code cells share one mirror file, so diagnostics and go-to-definition
  work across cells.
