EUROPA.VIM							*europa*

Europa.vim turns Vim/Neovim into a Jupyter notebook viewer. It runs on Deno
via denops.vim and keeps the host Python-free.

This file is a hand-written index. Each chapter ships as its own help file
under `doc/europa-<slug>.txt`. The API reference is auto-generated from
TSDoc into `doc/europa-api.txt`; everything else is hand-edited.
